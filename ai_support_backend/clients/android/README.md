# کلاینت اندروید (جای رزرو شده)

این پوشه فعلاً خالیه و برای کد اپ اندروید در آینده در نظر گرفته شده.

طبق تصمیمی که گرفتیم:
- هیچ منطق RAG، پردازش، یا فراخوانی مستقیم به Groq/Gemini در اپ موبایل انجام نمی‌شه.
- اپ فقط یک کلاینت سبک HTTP هست که به endpoint زیر وصل می‌شه:

```
POST https://chat.bluewaverobotics.ir/chat/mobile
```

قرارداد کامل درخواست/پاسخ (فیلدها، هدرها، کدهای خطا، نمونه کد Kotlin) در فایل
[`API_CONTRACT.md`](../../API_CONTRACT.md) در ریشه پروژه مستند شده.

وقتی کد اپ اندرویدتون آماده شد (یا حداقل ماژول شبکه‌ی چت)، می‌تونید یا:
1. لینک این پوشه رو به مخزن (repo) جدای اندروید بدید، یا
2. کد Kotlin/Compose مربوط به صفحه چت رو مستقیم همین‌جا نگه دارید (مثلاً به‌عنوان یک ماژول جدا یا فقط
   فایل‌های شبکه/API که با بک‌اند در ارتباطن، برای اینکه مستندسازی و نسخه‌بندی هر دو سمت با هم بمونه).
