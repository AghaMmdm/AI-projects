# کلاینت وردپرس

فایل `ai_chat_widget.php` عیناً همون کدیه که در پروژه قبلی (`wordpress_ai_support`) داشتید و
بدون هیچ تغییری منتقل شده. همچنان با endpoint قدیمی `/chat` (خروجی HTML) کار می‌کنه و نیازی به
تغییر در سایت وردپرس یا کد Code Snippets نیست.

نحوه نصب: طبق چیزی که قبلاً داشتید — کد داخل این فایل رو با پلاگین Code Snippets در بخش
`wp_footer` سایت وردپرس قرار بدید.
